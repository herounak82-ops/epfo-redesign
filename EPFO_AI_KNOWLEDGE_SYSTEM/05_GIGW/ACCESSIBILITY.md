# GIGW Accessibility

EPFO interpretation: interactive journeys must be usable by keyboard and assistive technology; focus and state changes must be perceivable; text, status, language, and controls must remain understandable at zoom and on varied devices. Evaluate both normal UI and error/recovery paths. Do not claim formal compliance certification from this synthesis alone.

Relevant rules: `GIGW-A-001`, `GIGW-A-002`, `GIGW-A-003`, `GIGW-A-004`.
