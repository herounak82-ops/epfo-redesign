# EPFO Design-System Gate

Every design-related task must evaluate the following before implementation: **typography, color theory, visual hierarchy, information architecture, accessibility, responsive behavior, government credibility, UX4G alignment, GIGW implications, and service-state clarity**. Only then decide whether motion, graphics, advanced interaction, 2.5D, or 3D materially improves the member goal. Default to no advanced effects when they add decoration rather than clarity.

The visual rule is: **a government service that has been properly designed**, not a startup pretending to be a government website. Do not introduce generic SaaS dashboard aesthetics, decorative 3D, unnecessary gradients, visual gimmicks, AI decoration, giant marketing heroes, excessive floating cards, or luxury/portfolio styling.

The output of a design task must identify the relevant UX4G foundation/component/pattern, token source, GIGW implication, accessibility behavior, responsive transformation, service states, and audit checks.
