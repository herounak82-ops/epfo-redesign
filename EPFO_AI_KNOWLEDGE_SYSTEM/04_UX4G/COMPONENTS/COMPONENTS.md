# UX4G Components

The supplied UX4G evidence identifies buttons, checkboxes, dropdown menus, form-field groups, text fields, avatars, cards, dividers, images, spinners, tables, tags, links, navbar, accessibility bar, focus ring, and identity/access components. These are implementation references, not claims that every component is already integrated into the EPFO app. Current mapping lives in `10_IMPLEMENTATION/COMPONENT_MAPPING.xml`.

Source and status: `SRC-UX4G-001`; current/verified at the supplied research level. Exact package/API behavior must be checked against the relevant current implementation source before use.
