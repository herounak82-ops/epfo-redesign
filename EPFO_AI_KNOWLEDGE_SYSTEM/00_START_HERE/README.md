# Start Here

Use this compact flow for every future task:

`TASK → AI_INSTRUCTIONS → CONTEXT_POLICY → CANONICAL → RETRIEVAL ROUTER → TASK ROUTE → RELEVANT RECORDS → IMPLEMENTATION → VALIDATION`

The system is deliberately selective. Start with the route registry, not the raw source folders. Open `90_RAW_SOURCE` only for provenance, a disputed interpretation, missing detail, or a full-system audit. The route package is the working context; the manifest and source register explain what each file is and why it exists.

For a design task, also read `03_DESIGN_SYSTEM/DESIGN_SYSTEM_GATE.md`. For a GIGW audit, read `05_GIGW/GIGW_MASTER.md` and the audit files. For an implementation task, read `10_IMPLEMENTATION/ARCHITECTURE.md`, the relevant route map, and the relevant mock fixture.
