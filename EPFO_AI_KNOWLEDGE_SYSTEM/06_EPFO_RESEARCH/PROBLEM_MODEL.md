# EPFO Problem Model

The supplied bad-journey report prioritizes five interconnected problems: fragile access, fragmented identity/KYC, claim uncertainty, legacy complexity around job changes and transfer, and recovery that becomes an escalation maze. The report’s grievance volumes and qualitative examples are prioritization evidence, not proof that all reported issues are pure UX defects or prevalence claims.

| Journey | User goal | Core redesign behavior |
|---|---|---|
| Access | Recover/view account | Preserve context, explain authentication state, avoid opaque failure. |
| KYC | Fix personal details | Show item-level health, owner, evidence need, and next action. |
| Claim | Get PF money | Explain prerequisites, status, reason, owner, and timing. |
| Transfer | Move PF after job change | Make source/destination employment and dependencies explicit. |
| Failure recovery | Fix a failed request | Turn error into a diagnostic recovery path and supported escalation. |

Research limitation: official production schemas and complete backend behavior are not established by current project sources.
