# Raw Source Policy

This directory preserves provenance only. Raw files are never default context. Open them for provenance, disputes, missing detail, or a full-system audit. Derived records must point to source IDs. Do not duplicate raw documents into active layers.

Preserved sources include the supplied GIGW extracted text, the UX4G dossier, EPFO research materials, and metadata for the architectural reference archive. The reference archive is methodology only; its unrelated portfolio content is excluded from EPFO active knowledge.
