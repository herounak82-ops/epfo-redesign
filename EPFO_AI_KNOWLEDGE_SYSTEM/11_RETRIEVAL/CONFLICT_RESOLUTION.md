# Conflict Resolution

When records disagree: identify the conflict, check whether one is historical, compare current authority and freshness, check scope, do not silently overwrite, record the unresolved issue, and create a canonical decision only when the project intentionally resolves it. Legacy UX4G material is not current merely because it is detailed. Raw sources are reopened only when the derived record is insufficient or disputed. If evidence is unavailable, write “Not established by current project sources.”
